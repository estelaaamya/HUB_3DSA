## 1. Nombre propuesto

Nombre proporcionado por la estudiante para la empresa de software del equipo. El grupo está integrado por seis personas.

## 2. Idea de negocio
Empresa académica de desarrollo de software que ofrece:
- Sistemas de control de inventario y ventas para pequeños negocios.
- Diseño y desarrollo de páginas web.
- Bases de datos y sistemas de registro.
- Tiendas en línea y configuración de plataformas como PrestaShop.

Pequeños comercios, cafeterías, emprendimientos, spas y negocios locales que necesiten organizar sus operaciones o tener presencia digital.
